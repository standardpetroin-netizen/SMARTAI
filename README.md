# SmartAI Society

AI & autonomous smart living platform: a multi-tenant operating system for residential
welfare associations, high-rises and gated townships. Includes super-admin society
provisioning, resident and guard terminals, IoT water operations, QR visitor passes,
and a Flutter companion app.

## Stack

- React 19 + Vite 8 + Tailwind 4 (frontend in `src/`)
- Express + sql.js SQLite (`server.ts`, `src/server/db.ts`)
- Flutter app in `flutter_app/`
- VPS deployment assets in `hostinger_deploy/`

## Run locally

```bash
npm install
cp .env.example .env      # optional: GEMINI_API_KEY, APP_URL
npm run dev               # Express + Vite middleware on http://localhost:3000
```

## Production build

```bash
npm install
npm run build             # vite build -> dist/, esbuild -> server.js
npm start                 # node server.js
```

## Deployment settings (Hostinger Node.js / VPS)

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Start command | `npm start` |
| Entry file | `server.js` |
| Output directory | `dist` |
| Node.js | 22 |

`server.js` is generated by the build from `server.ts`, so it stays in sync with the
source. The SQLite database lives at `data/smartaisociety.sqlite` and is created on
first boot if missing.

## API

- `GET /api/health` - service and table health check
- `POST /api/auth/login` - role based login (resident, guard, society admin)
- Remaining endpoints are defined in `server.ts`

SQLite-backed, with a MySQL dump generator in `hostinger_deploy/smartaisociety_hostinger.sql`
for migrating to a managed database.
